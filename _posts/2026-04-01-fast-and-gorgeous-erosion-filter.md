# Fast and Gorgeous Erosion Filter - 高速で美しい侵食フィルタ
魅せる谷筋を一発で生成する「GPUフレンドリーな侵食フィルタ」—山肌の枝分かれ渓谷を高速に描く新発想

## 要約
元記事は、雨のドロップを逐次シミュレーションせずに「見た目の侵食」を高速かつチャンク生成可能にする、勾配に沿ったストライプノイズベースの侵食フィルタを解説する。

## この記事を読むべき理由
巨大地形やリアルタイム描画を扱う日本のゲーム／CG開発者にとって、GPUで並列評価でき、チャンク生成やローメモリ環境でも使える侵食表現は実用的かつ即戦力になるため。

## 詳細解説
- 基本アイデア  
  - 元の高さ関数 h(x) とその勾配 ∇h を利用し、勾配の下向き（負勾配）に沿って「ストライプ」を重畳することで谷筋と尾根を表現する。各オクターブ（スケール）でストライプを追加し、小スケールの流路は大スケールの流路から枝分かれするように見せる。
- ピボット／セル分割による回転ノイズ  
  - ストライプを回転させる際、単一ピボットは離れるほど歪むため、格子セルごとにランダムピボット（Worley風）を置き、それぞれのセルで回転→隣接セルとブレンドして連続的に繋げる。ストライプは高さオフセットに対して cos、導関数（斜度）に対して sin を利用することで滑らかに混ざる。
- ピークとバレー（局所極値）の扱い：frequency vs fade  
  - frequencyアプローチ：ストライプ周波数を勾配（斜度）に比例させ、平坦部で幅を太くする。ピークでは常に尾根側に寄るが、谷底が膨らむ副作用がある。  
  - fadeアプローチ（筆者の提案）：ストライプ幅を一定に保ち、斜度が0に近づく箇所でストライプを段階的にフェードアウトする。フェード先を谷→尾根で変えることでピークと谷を同時に良好に保持できる。フェードターゲットは標高に基づくパラメータ化が有効。
  - 標準的な正規化関数として inverse_lerp を使う：$ \mathrm{inverse\_lerp}(a,b,v)=\dfrac{v-a}{b-a} $。
- 斜度に基づくシェイピング（ディスコンティニュイティ対策）  
  - 単純に $t^{0.5}$（平方根）を使うとピーク付近で急増し不連続が出る。改善策として筆者は次のイージングを使った：  
    $$ \mathrm{ease\_out}(t) = 1 - (1 - \mathrm{sat}(t))^2 $$  
    これにより斜度ゼロ付近で穏やかに立ち上がるため、複数オクターブの重ね合わせで折り目が目立たなくなる。
- 鮮明な枝分かれを得るための3つの工夫  
  1. stacked fading：オクターブ毎のフェード強度を積み上げて大スケールの稜線を殺さない。  
  2. normalized gullies：各オクターブの振幅調整を正規化してスケール間でのコントラストを保つ。  
  3. straight gullies：局所方向性を強めに調整して主要谷筋が折れずに伸びるようにする。  
- 実装面の利点  
  - 各点を独立評価できる（ピクセルシェーダ／コンピュート向き）、チャンク分割が容易、高速でメモリ効率良し。Shadertoyベースの実装が参照可能。

コード例（GLSL風）
```glsl
// glsl
float inverse_lerp(float a, float b, float v) {
    return (v - a) / (b - a);
}
float ease_out(float t) {
    float v = 1.0 - clamp(t, 0.0, 1.0);
    return 1.0 - v * v;
}
```

## 実践ポイント
- まずShadertoy実装で挙動を試す：セルサイズ／ストライプ幅／オクターブ数を調整。  
- フェードターゲットを標高に依存させるとピーク／谷の制御が容易（inverse_lerpで正規化）。  
- 大地形をチャンク生成する場合、必ずセル依存のランダムピボットを再現可能シードで決めること。  
- シャープなV字谷が欲しいなら fadeアプローチ＋ease_out を試す。平滑な谷底が欲しいなら frequencyアプローチ＋低高度フェード。  
- 日本の地形（急峻な山地やV字谷が多い）を表現するなら、fadeでの高度依存フェードとstraight gulliesの組合せが相性良し。

元記事は多数のビジュアルとShadertoyリンクを備えており、実装例を参照すると学習コストが低い。実プロジェクトではパラメータ化してエディタで微調整できるようにすると扱いやすい。
