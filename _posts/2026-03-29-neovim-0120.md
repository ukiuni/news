# Neovim 0.12.0 - Neovim 0.12.0リリース
「今すぐ試したいNeovim 0.12 — 軽量コアとマルチプラットフォーム配布の最新安定版」

## 要約
Neovim 0.12.0 が正式リリースされました（タグは署名済み）。LuaJIT 2.1.177... を含む Release ビルドで、Windows/Mac/Linux 向けに公式バイナリ（zip/msi/tarball/AppImage）とARMビルドが提供されています。

## この記事を読むべき理由
Neovim は軽量で拡張しやすいエディタとして国内でも人気が高く、本リリースは公式配布が整理されたことで導入のハードルが下がっています。特に Apple Silicon や Linux のディストロでの導入手順が明確になっているため、環境構築が楽になります。

## 詳細解説
- リリース情報: タグ v0.12.0（コミット fc7e5cf）、署名付き（GPG key ID: 3E4213088345C16D）で信頼性あり。Release ビルドは開発向けではなく安定運用向け。
- ランタイム: LuaJIT 2.1.1774638290 を同梱。Neovim のプラグインや設定で Lua を活用している人は互換性確認を。
- 配布形式:
  - Windows: nvim-win64.zip / nvim-win-arm64.zip、または nvim-win64.msi / nvim-win-arm64.msi。MSI インストール後に nvim.exe をターミナルで起動。Windows Server 環境では vcruntime140.dll が必要な場合あり。
  - macOS: x86_64 / arm64 の tar.gz。配布ファイルに対して `xattr -c` を実行すると「不明な開発元」警告回避可能。展開後のバイナリを実行。
  - Linux: x86_64 / arm64 の AppImage と tarball を提供。AppImage は実行権限付与（chmod u+x）して実行、FUSE が無い場合は `--appimage-extract` で中身を取り出せる。glibc のバージョンに依存するため古い環境向けに非公式ビルドも案内あり。
- ドキュメント: 変更履歴（Changelog）とニュース（:help news）を参照。公式リリースページにインストール手順がまとまっている。

## 実践ポイント
- 自分の環境に合わせてアーキテクチャ（x86_64 / arm64）を選択する（Apple Silicon や Raspberry Pi などでの最適化）。
- macOS ではダウンロード後に xattr -c を実行して実行警告を回避。
- Linux で AppImage を使う場合は chmod で実行権限を与えるか、FUSE が無ければ --appimage-extract で展開して実行。
- Windows Server で動かない場合は vcruntime140.dll の有無を確認。
- セキュリティを意識するならリリースタグの署名（GPG）を検証してからインストールする。

（詳細な変更点やバグ修正はリリースの Changelog / News を参照してください。）
