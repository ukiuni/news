# EYG is now open source - EYG がオープンソースになりました
EYG（Eat Your Greens）──「安全で軽量なスクリプト言語」をあなたの手元で試せるチャンス

## 要約
EYG プロジェクトが公式にオープンソース化され、Apache 2.0 ライセンスで公開されました。言語仕様の JSON 化と、Gleam で書かれた最初の高品質なインタープリタ向けパッケージ群が整備されています。

## この記事を読むべき理由
- 日本でも組み込み・サーバー・ブラウザを横断する軽量言語や安全なスクリプト環境への需要は高いです。  
- EYG は「効果（effects）を管理する」設計で、LLM やユーザー向けスクリプトをより安全に実行できる点が魅力です。

## 詳細解説
- ライセンスとコード構成：リポジトリは Apache 2.0 で公開。コードはほぼ Gleam に統一され、言語仕様は JSON で定義されています。  
- インタープリタとパッケージ：外部効果（ファイル、ネットワーク等）を実装するパッケージが整備され、テストやCI、ドキュメントも追加済み。余計な実験コードは別に移動し、コアを磨いています。  
- 大規模プログラム向けエディタ：パッケージ／ワークスペースを跨いで操作できる構造化エディタの開発が進行中。単一モジュールより大きなプロジェクト向けの UX が焦点です。  
- AIとの親和性：EYG の管理された効果モデルは、LLM に対するスクリプト実行環境として安全性が高く、ブラウザよりもターミナル内での LLM 活用が有望とされています。  
- 「どこでも動く」設計：Arduino、Auth0 ルール、Nginx、ブラウザ、サーバーでの実行例があり、新しい実装（ランタイム）を一つ作りやすい構造が目標です。これによりエコシステム拡大を狙っています。

## 実践ポイント
- リポジトリを確認：LICENSE（Apache 2.0）と JSON の言語仕様から読み始める。  
- Gleam を触ってみる：EYG 実装が Gleam ベースなので、Gleam を学ぶと貢献しやすい。  
- インタープリタのパッケージを起動：テストや CI を動かして動作を確認し、外部効果の仕組みを理解する。  
- エディタのプレビューを試す：ワークスペース単位の編集体験を確認してフィードバックを送る。  
- ランタイム実装を検討：自社プロダクト向けに小さな EYG インタープリタ（例：WASM、組み込み用）を作れば貢献と差別化に繋がる。  
- LLM安全運用に応用：任意の bash より安全なスクリプト環境として EYG を試し、AI連携の導入を検討する。

オープンソース化は「参加」の合図です。まずはリポジトリを覗いて、小さな実験から始めてみてください。
