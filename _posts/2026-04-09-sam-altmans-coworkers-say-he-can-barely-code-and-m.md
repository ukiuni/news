# Sam Altman’s Coworkers Say He Can Barely Code and Misunderstands Basic Machine Learning Concepts - サム・アルトマンはほとんどコードを書けず、基礎的なML概念を誤解していると同僚が語る
クリックせずにはいられない見出し：CEO神話が崩れるとき──「顔」と「技術」のギャップがもたらす現実

## 要約
元記事（New Yorker を引用した Yahoo 報道）によれば、OpenAIのCEOサム・アルトマンは同僚から「プログラミングや機械学習の基礎理解が乏しい」と評され、経営術で技術的な欠点を覆い隠してきたとされる。この記事はその指摘と企業ガバナンス上の意味を整理する。

## この記事を読むべき理由
トップの技術理解と組織の信用は、AI開発の安全性・透明性に直結する。日本の企業や研究者も同様のリスクやガバナンス課題に直面し得るため、対策のヒントが得られる。

## 詳細解説
- 出典と性質：元報道はNew Yorkerの記事を基にしており、「同僚や元研究者の証言」を引用している。したがって主張は内部関係者の視点に基づく報道であり、事実関係は確認中の点がある。
- 指摘内容の要点：
  - アルトマンの技術的専門性について「コードを書けない」「機械学習の基本用語を混同する」との証言がある。
  - 経営手腕としては「ボードや仕組みを表面上作るが、実際に制約が必要な局面で逸脱する」との評価がある（内部者の引用）。
  - 一部では、過度なカリスマ性が問題の隠蔽に寄与しているという批判や、ガバナンス上の重大リスクに結び付ける見方も示されている。
- 技術的含意：
  - CEOがコア技術を理解していない場合、製品評価・リスク判断・外部公開の是非に齟齬が生じやすい。
  - 機械学習プロジェクトでは、モデル性能だけでなくデータ品質、評価基準、再現性、配布ポリシーなど非技術的判断が重大影響を持つため、経営層の基礎理解不足は意思決定ミスを誘発する可能性がある。

## 実践ポイント
- ガバナンス強化：取締役会や外部監査による技術レビューを定期的に実施する。
- ドキュメント化：モデル仕様・評価方法・データガバナンスを明文化して経営判断の根拠にする。
- 技術リテラシー：経営層向けに機械学習の要点（評価指標、分布シフト、再現性）を短く体系化して共有する。
- 外部検証：重要モデルは第三者評価や外部セキュリティ監査を導入する。
- 日本企業への示唆：カリスマ経営に依存せず、技術とガバナンスを両輪で回すことが、信頼と事業継続性を守る最短ルート。
