# Learn Claude Code by doing, not reading - 読むより体験で学ぶ：Claude Code
魅力を直感でつかむ！ブラウザで即プレイできるClaude連携ハンズオン

## 要約
Ahmed Nagdyが作った「Claude Code」は、ブラウザ上で動く11のインタラクティブ学習モジュール（端末シミュレータ／コンフィグ生成／クイズ付き）で、セットアップ不要・APIキー不要でClaude連携の実践スキルを身につけられます。

## この記事を読むべき理由
Claudeや類似LLMを使った実装は国内開発でも増加中。設計や設定ファイル（CLAUDE.md）、スラッシュコマンドやスキルの作り方を「読む」だけでなく「試しながら」学べる実践教材は、日本のエンジニアが素早くプロダクト適応するために有効です。

## 詳細解説
- 何ができるか：ブラウザ内の端末シミュレータでスラッシュコマンド、フック、スキルを試せる。実際に動く感覚を得ながら学習可能。  
- コンフィグ生成：インタラクティブなフォームでCLAUDE.mdやhooks、plugin設定、MCPサーバ設定を自動生成し、プロジェクトへコピーして使えます。CLAUDE.mdはClaudeのメモリ／動作定義をまとめる主要な設定ファイルです。  
- 学習構成：全11モジュール（初心者〜上級）。例：Slash Commands（30分・初心者）、Memory & CLAUDE.md（45分・初心者）、Project Setup（45分）など。各モジュールは学習→練習→クイズで理解度を確認。誤答時は単なる正解表示ではなく解説が返る設計。  
- ツール群：Playground（フルサイズ端末サンドボックス）、Config Builder、Cheat Sheet（印刷用ショートリスト）、Feature Index（機能検索）、Resources（テンプレ／外部ガイド）。  
- ハンズオンの利点：APIキー不要で試せるため企業環境や個人学習で手軽に導入でき、設定ミスや挙動を早期に検証できます。作者とバージョン情報（Ahmed Nagdy、v1.1.1、luongnv89のリファレンスに着想）あり。

## 実践ポイント
- まずは「Slash Commands」モジュールを30分で一通り触る。手を動かすことでCLI寄りの操作感を理解。  
- Config BuilderでCLAUDE.mdを生成して自プロジェクトに貼り付け、動作差分を比較する。  
- Playgroundでスキル／フックを繰り返し実行し、想定外のレスポンスを検証する。  
- Cheat Sheetを印刷して、よく使うコマンドやファイル構成をチームで共有する。  
- 日本語コンテンツや企業要件（データ保護、オンプレ要件）がある場合は生成した設定を起点にローカライズを検討する。
