# Nashville library launches Memory Lab for digitizing home movies - ナッシュビル図書館が家庭用映像をデジタル化する「Memory Lab」を開設
手元のVHSやスライドを“図書館で自分で”デジタル化――無料で始める地域のデジタル保存プロジェクト

## 要約
米ナッシュビル公立図書館が、VHSやポラロイド、スライドを自分でデジタル化できる予約制の「Memory Lab」をドネルソン支部に開設。機材・ソフトを使って高解像度ファイルに変換でき、スタッフのサポートも受けられる。

## この記事を読むべき理由
アナログ資産の劣化は世界共通の課題で、技術とコミュニティ運営の組み合わせで解決できる好例。技術者や地域サービス担当者は、低コストで住民の文化資産を守る仕組みづくりのヒントを得られる。

## 詳細解説
- 対象メディア：VHSテープ、家庭用ムービー、ポラロイド写真、スライドなどのアナログ媒体を想定。  
- 仕組み：図書館が用意した変換用ハード（VCRやキャプチャ機器、スライドスキャナ等）とソフトで、アナログ信号をデジタルファイル（高解像度映像やJPEG/PNG等）に変換するセルフサービス方式。  
- サポート：利用者は4時間枠を予約し、作業中は図書館スタッフの補助を受けられる。変換後のファイルは利用者が持ち帰る（高解像度ファイル保存用に外付けHDD持参推奨）。  
- コスト比較：民間業者に依頼すると1本あたり数千円（記事では約$30相当）の費用がかかるが、Memory Labは無料で提供。  
- 背景・波及：ワシントンD.C.やロサンゼルス、ブルックリンなどでも同様の公共サービスが広がっており、地域の映像を時系列で残す「タイムカプセル」的な価値もある。

## 日本市場との関連
- 日本でも家庭に眠るVHSやフィルムは多く、自治体図書館や公民館で同様のサービスを導入すれば文化資産保全と地域交流の両立が可能。  
- 技術面では、低コストのキャプチャデバイスやオープンソースの変換ツール（OBS、FFmpeg等）を組み合わせれば導入コストを抑えられる点が参考になる。

## 実践ポイント
- 地元図書館に同様のサービスがあるか確認する。  
- 予約時は4時間程度を確保。作業用に外付けHDD（容量余裕あり）を持参。  
- テープやスライドは事前にラベル付けし、劣化が激しいものは専門保存の相談を。  
- 変換後は複数の場所にバックアップし、ファイル名・撮影日・場所などのメタ情報を残す。
